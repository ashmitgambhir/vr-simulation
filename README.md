# vr-simulation

This workspace now contains a Unity-based VR project scaffold for the "How Virtual Reality Tricks Your Brain" experience.

## What is included

- Unity project metadata and package manifest for XR/VR development
- Initial scene at Assets/Scenes/MainMenu.unity
- Core game structure under Assets/Scripts for:
  - bootstrap and initialization
  - save and settings management
  - UI, audio, interaction, and scene flow
  - player controller foundation
- Standard Unity folder structure aligned with the implementation plan

## Getting started

1. Open the project in Unity Hub using this folder.
2. Let Unity resolve the packages from Packages/manifest.json.
3. Open the MainMenu scene and start building the educational modules.

## Notes

The scaffold is intentionally minimal and focused on the architecture described in the project documents so it is ready for expansion without extra boilerplate.
